# Early Digital

Камера для iOS та Android на React Native, яка знімає так, як знімали телефони 2002–2013 років: від VGA-камери Nokia 7650 до iPhone 5s.

Це не набір фільтрів. Кожен знімок проходить через фізичну модель камери того часу: оптику, сенсор із Bayer-мозаїкою, процесор обробки (ISP) і JPEG-кодер. Усе рахується на GPU через Skia-шейдери. Кожен профіль описаний як технічна специфікація, а не як «пресет»: світлосила, діапазон ISO, ємність пікселя, шум зчитування, перехресні завади кольорових фільтрів, різкість, якість JPEG, роздільність і частота кадрів екрана.

## Що вміє

- **Колесо часу.** Прокручуєш роки 2002 → 2013, і камера перемикається на телефон під позначкою: Nokia 7650, 6230i, 6300, N95, оригінальний iPhone, 3GS, 4, 5s.
- **Живий видошукач на GPU.** Кожен кадр камери проходить однопрохідну версію конвеєра. Ти бачиш шум, кольори й м'якість ще до знімка.
- **Автентичний режим.** Видошукач опускається до роздільності, глибини кольору й FPS екрана телефона (у 7650 це 176×208, 4096 кольорів, ~8 кадрів/с), а затвор спрацьовує із затримкою, як тоді.
- **Чесні обмеження.** У телефонів без фронтальної камери не можна перемкнутися на селфі, у телефонів без спалаху він недоступний, на фокус-фіксі тап-для-фокусу нічого не робить. Індикатор фокусу теж відповідає епосі: зелені кути в Nokia, синій квадрат в iPhone.
- **Експозиція з фізики.** З EXIF вихідного кадру береться реальна яскравість сцени (EV). Далі автоматика старого телефона виставляє витримку й ISO в межах його можливостей. У темряві він «закінчується»: недоекспозиція, шум на максимальному підсиленні, змазування від тремтіння рук на довгій витримці, акварельне шумозаглушення, втрата насиченості.
- **Пере-проявка.** Оригінал зберігається, тож будь-який кадр можна перепроявити як інший телефон.
- **Справжні файли.** Імена як на телефоні (`Image(001).jpg`, `IMG_0042.JPG`, `15062007001.jpg` у N95), EXIF з моделлю, витримкою та ISO симульованої камери. JPEG справжній, з реальним квантуванням і 4:2:0, а не намальованими «артефактами».
- **Імпорт.** Будь-яке фото з галереї можна проявити як зняте старим телефоном. Так додаток працює і в симуляторі, де камери немає.

## Конвеєр проявки

```
JPEG з камери ──► орієнтація + кроп + 2× оверсемплінг
   │
   ├─ 1. Оптика      дисторсія, хроматична аберація, м'якість до країв,
   │                  тремтіння рук, засвітка, віньєтка, спалах
   ├─ 2. Сенсор      розширення DR навколо середнього тону сцени, експозиція,
   │                  перехресні завади фільтрів, Bayer RGGB, дробовий шум +
   │                  шум зчитування на симульованому підсиленні, смуги,
   │                  гарячі пікселі, кліпінг, АЦП 8/10 біт
   ├─ 3. ISP         білінійне дебаєрування (з «блискавкою» на краях),
   │                  помилка lens shading, AWB «сірий світ», кольорова матриця,
   │                  плече світлих, гамма, S-крива, насиченість
   ├─ 4. Шумодав     білатеральний фільтр яскравості + широкий фільтр кольоровості
   ├─ 5. Різкість    нерізке маскування без обмеження ореолів + «кольоровий почерк»
   └─ 6. JPEG        якість конкретного телефона + EXIF
```

Шейдери лежать у [src/pipeline/shaders.ts](src/pipeline/shaders.ts), фізична модель експозиції в [src/pipeline/exposure.ts](src/pipeline/exposure.ts), профілі камер у [src/profiles/index.ts](src/profiles/index.ts).

Шумна кольорова «каша» старих телефонів виникає тут сама собою, без підмальовування. Дешеві кольорові фільтри змішують канали. ISP частково обертає це змішування кольоровою матрицею, і великі позадіагональні коефіцієнти підсилюють шум сенсора в кольорові плями. Саме так це було і в реальних телефонах.

## Стек

- Expo SDK 58, React Native 0.88 (New Architecture), Expo Router
- [VisionCamera 5](https://github.com/mrousavy/react-native-vision-camera) (Nitro) + `react-native-vision-camera-skia` для живого шейдера у видошукачі
- [React Native Skia](https://github.com/Shopify/react-native-skia) (SkSL runtime effects) для всієї проявки на GPU
- `react-native-worklets` / Reanimated 4, `expo-file-system`, `expo-media-library`, `expo-image-picker`

## Запуск

Потрібен dev build (VisionCamera має нативний код, тому Expo Go не підійде):

```bash
npm install
```

```bash
npx expo run:ios
```

```bash
npx expo run:android
```

У симуляторі iOS камери немає, тому використовуй кнопку **IMPORT**.

## Лабораторія (desktop)

Конвеєр не імпортує React Native: Skia передається як залежність. Тому той самий код запускається в Node через CanvasKit (web-бекенд RN Skia). Це дає змогу налаштовувати профілі й ловити регресії без телефона:

```bash
npm run lab -- --max 1024 path/to/photo.jpg
```

Результат: `lab/out/index.html`, контактний аркуш усіх телефонів. Корисні прапорці: `--ev 4`, щоб симулювати сутінки; `--only n95,5s`; `--flash`.

Шейдер живого видошукача (звичайний і автентичний режими) можна перевірити на фото без камери:

```bash
npx tsx lab/preview.ts path/to/photo.jpg
```

У dev-збірці є службовий маршрут для симулятора, де немає камери, а системний вибір фото часто не показує мініатюри. Поклади JPEG у Documents застосунку і відкрий `earlydigital://debug?file=photo.jpg&profile=vga-2002`. У production-збірці маршрут вимкнений.

## Перевірки

```bash
npm run typecheck
```

```bash
npm test
```

Тести покривають запис і читання EXIF, інваріанти кольорових матриць (нейтральні кольори лишаються нейтральними), монотонність моделі автоекспозиції, повну проявку кожним профілем через CanvasKit, детермінованість за seed і обробку EXIF-орієнтації.

## Структура

```
src/
  app/            екрани (Expo Router): камера, картка пам'яті, знімок
  pipeline/       шейдери, модель експозиції, кольорова математика, develop()
  profiles/       специфікації телефонів
  exif/           мінімальні читач і записувач EXIF
  storage/        знімки й налаштування на диску
  ui/             видошукач, колесо часу, індикатор фокусу, лоток проявки
  darkroom.ts     черга проявки, автозбереження у Фото
lab/              desktop-лабораторія на CanvasKit
test/             тести (node:test + tsx)
```

Профілі натхненні телефонами відповідних виробників і використовуються лише описово. Назви Nokia та iPhone належать їхнім власникам.
